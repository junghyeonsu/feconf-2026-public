# HTML 내보내기와 발표자 모드

2026-10-24. 현재 FECONF 덱 전용 도구이며 장표 소스를 수정하지 않는다.

## 실행

```bash
bun scripts/export-html.mjs
bun scripts/export-html.mjs output/html/my-presentation.html
```

- `scripts/export-html.mjs`: 실제 React 소스와 React 런타임을 브라우저 번들로 만들고 이미지·폰트·영상과 발표자 노트를 단일 HTML에 포함한다. Bun과 레포에 설치된 React를 사용하며 의존성을 추가하지 않는다. 원본의 폰트 등록, Canvas/WebGL 효과와 활성 페이지에 따른 재생을 실행하며 뷰어의 기본 CSS도 포함한다.
- `scripts/presenter-runtime.js`: 청중용 장표 이동·페이드·영상 재생과 별도 발표자 창을 담당한다. 생성 과정에서 HTML 안에 삽입되므로 실행 시 외부 JS 파일은 필요 없다.
- 기본 출력은 `output/html/feconf-2026-standalone.html`이다. 경로 인자는 레포 루트 기준이며 기존 대상 파일을 갱신한다. 에셋 누락, 지원하지 않는 미디어 형식, 노트 수 불일치는 오류로 처리한다.
- `<출력 경로>.verification.json`에는 장수·노트 수·에셋 수·영상 수·파일 크기·원본 소스 SHA-256을 남긴다. 임시 TSX 모듈은 성공·실패에 관계없이 정리한다.

## 발표할 때

1. 생성한 HTML을 브라우저에서 연다.
2. `P` 키로 발표자 창을 연다. 브라우저가 차단하면 해당 파일의 팝업을 허용하고 다시 누른다.
3. 청중 창을 외부 화면으로 옮기고 `F` 키로 전체 화면을 사용한다. 발표자 창은 노트북 화면에 둔다.
4. 어느 창에서든 `← / →`, PageUp/PageDown, Home/End로 이동할 수 있다. 발표자 창의 이전·다음 버튼도 같은 상태를 갱신한다. 대본 영역은 스크롤할 수 있다.

발표자 창에는 현재·다음 장표, 현재 대본, 대본 글자 크기 조절, 경과 타이머가 있다. 타이머는 발표자 창을 처음 열 때 시작하며 일시정지·재시작·초기화할 수 있다. 마지막 장표에서는 다음 버튼을 비활성화한다. 미리보기의 영상은 포스터로 표시하고 청중 창에서만 재생한다. 청중 창이 닫히면 발표자 컨트롤도 비활성화된다. 청중 창 새로고침은 페이지와 타이머 상태를 초기화하므로 `P`로 다시 연결한다.

동기화는 생성한 청중 창과 그 창에서 연 발표자 창 사이에서 동작한다. HTML을 따로 두 번 여는 것은 동기화된 두 창을 만드는 방법이 아니다.

## 범위와 검증

- 현재 64장·64개 대본, 미디어·폰트 에셋 81개, 영상 5개를 포함한다. 에셋은 파일당 한 번 포함하고 Blob URL로 재사용한다.
- Chrome의 `file://` 환경에서 1·2페이지 WebGL 그라데이션 실행과 폰트 로딩, 발표자 창 열기, 양방향 이동과 마지막 페이지의 대본을 확인했다. 브라우저 실행 오류는 없었다.
- 원본 2페이지와 HTML의 제목·부제 글꼴, 크기, 줄 높이, 좌표를 대조했다. 정적 렌더링에서 누락되던 폰트와 효과뿐 아니라 기본 CSS에 의존하는 배치도 보존한다.
- 발표자 미리보기의 Canvas는 현재 프레임 이미지로 복사하고 영상은 포스터로 표시한다. 청중 창에서 애니메이션과 영상을 실행한다.
- 실제 발표용 브라우저·외부 디스플레이의 팝업, 전체 화면, 성능은 해당 환경에서 리허설한다.
- 산출물에는 발표자 대본도 포함된다. 제출본에 대본을 포함하면 안 되는 경우에는 장표만 포함된 PDF를 사용한다.

`output/`의 HTML·PDF·캡처와 바탕화면 복사본은 로컬 산출물이다. Git에는 생성·발표자 코드와 사용 안내만 포함한다.

## 공개 웹과 참고 링크

```sh
bun scripts/export-html.mjs --public
```

`output/public/index.html`과 `assets/`를 생성합니다. 이 폴더만 정적 호스팅에 올립니다. 기존 청중 화면과 발표자 창을 그대로 사용합니다. `P`로 발표자 창을 열면 현재 장표의 대본과 참고 링크를 함께 볼 수 있습니다. 별도의 대본 패널이나 툴바는 추가하지 않습니다.

`docs/presentation-script.md`의 참고 링크를 발표자 창에 표시합니다. 단일 HTML 내보내기의 발표자 창에도 같은 링크가 표시됩니다. 장표 원본은 수정하지 않습니다. 대사와 페이지 순서가 원본과 다르면 빌드가 실패합니다.

공개 웹은 에셋을 상대 경로로 참조하므로 저장소 이름에 따른 base 설정이 필요하지 않습니다. GitHub Pages에서는 이 명령의 출력 폴더를 배포 대상으로 사용합니다. 일반 `bun run build`는 편집 도구의 기본 뷰어를 만드는 별도 명령입니다.
